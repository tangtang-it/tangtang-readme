# 动画GIF制作指南

> 作者：糖糖it

## 平台支持说明

- **GitHub支持GIF动图**，可以直接在README中展示动态效果
- **GitHub不支持SVG内联动画**，SMIL、CSS动画、JavaScript在SVG文件中均不生效
- 解决方案：**动效用GIF展示 + 静态SVG作为回退方案**
- 用户可选择查看动态GIF版本或静态SVG版本

## 何时使用动效

动效应该有目的性，避免为了动而动。适合使用动效的场景：

### 产品演示
- 展示产品核心功能流程
- 界面交互操作演示
- 功能特性动态展示

### 交互流程
- 用户操作路径演示
- 点击、滑动等手势指引
- 状态变化过渡动画

### Before/After对比
- 优化前后效果对比
- 使用前后变化展示
- 数据增长动态呈现

### 打字效果
- 终端命令行演示
- 代码实时输入效果
- 标题逐字出现动画

## 动效设计原则

### Opt-in原则
- **动效默认不自动播放**
- 提供明显的播放/暂停控制
- 用户主动选择观看动效
- 尊重用户偏好，减少干扰

### 循环时长
- **循环时长控制在3-5秒**
- 太短会让用户看不清内容
- 太长会让用户失去耐心
- 单循环内能完整展示核心信息

### 文件大小
- **文件大小控制在2MB以内**
- 过大文件加载缓慢，影响体验
- 优先保证核心信息清晰
- 通过优化参数减小体积

### 无缝循环
- **首尾帧必须无缝衔接**
- 避免循环时出现跳帧
- 结尾状态自然过渡到开始状态
- 观看体验流畅不突兀

### 动效节奏
- **入场 → 稳定停留 → 出场**
- 入场：元素进入画面，时间占比20%
- 稳定停留：核心内容展示，时间占比60%
- 出场：元素退出画面，时间占比20%
- 给用户足够时间阅读核心信息

## 工具使用流程

使用`scripts/render_motion_gif.py`工具进行GIF渲染：

### 1. 准备动画帧
- 创建SVG动画序列或HTML动画页面
- 确保每一帧内容准确
- 确定帧率和总时长
- 设计关键帧过渡

### 2. 配置渲染参数
- 设置输出尺寸（建议宽度1200px以内）
- 设置帧率（建议15-24fps）
- 设置循环次数（0为无限循环）
- 设置颜色数（建议128-256色）

### 3. 执行渲染
```bash
python scripts/render_motion_gif.py \
  --input animation.html \
  --output demo.gif \
  --fps 20 \
  --colors 256 \
  --dither floyd-steinberg
```

### 4. 优化压缩
- 检查输出文件大小
- 必要时降低帧率或颜色数
- 使用gifsicle进一步优化
- 验证播放流畅度

## 参数设置详解

### 帧率设置
- **12fps**：适合简单动画，文件最小
- **15fps**：平衡流畅度和文件大小，推荐
- **24fps**：流畅度最佳，文件较大
- 避免超过30fps，人眼难以区分但文件激增

### 颜色数设置
- **64色**：适合单色或配色简单的动画
- **128色**：平衡色彩和大小，推荐
- **256色**：GIF最大颜色数，色彩丰富
- 颜色数翻倍 ≈ 文件大小翻倍

### Dither设置
- **none**：无抖动，色块明显，文件最小
- **floyd-steinberg**：弗洛伊德-斯坦伯格抖动，效果自然，推荐
- **bayer**：有序抖动，复古像素风格
- 抖动会增加文件大小，但提升渐变质量

### 尺寸设置
- 宽度建议：800px - 1200px
- 高度按比例自适应
- 避免超过1920px宽度
- 尺寸与文件大小成平方关系

## 常见问题处理

### 文件过大
1. 降低帧率（15fps → 12fps）
2. 减少颜色数（256 → 128）
3. 缩小输出尺寸
4. 裁剪掉不必要的边缘区域
5. 使用gifsicle -O3优化

### 播放不流畅
1. 检查是否有复杂透明效果
2. 增加关键帧密度
3. 避免跨度过大的位移
4. 适当提高帧率

### 循环有跳帧
1. 确保首尾帧完全一致
2. 检查最后一帧停留时间
3. 使用blend模式平滑过渡
4. 渲染时添加循环安全帧

### 文字模糊
1. 文字尽量放在静态SVG版本中
2. GIF中文字避免过小
3. 提高渲染分辨率后缩放
4. 考虑文字使用纯色无抗锯齿
