# 糖糖it SVG制作规范

**作者：糖糖it**

---

## 1. SVG适用场景

纯SVG适用于以下场景：

- **确定性布局**：像素级精确控制的图形元素
- **排版**：标题、标签、文字装饰
- **图表**：数据可视化、流程图、架构图
- **标题系统**：Hero头图、Section标题装饰

**混合方案参考：**
- 混合SVG（SVG + 栅格图像）：参考 `hybrid-svg-production.md`
- 动画效果：参考 `motion-production.md`
- **注意**：GitHub 不支持 SVG 内动画，请使用静态 SVG

## 2. 画布起点规范

| 元素类型 | 推荐尺寸（viewBox） | 边距预留 |
|---------|-------------------|---------|
| Hero头图 | 1200 × 300~420 | 距边缘 48~64 单位 |
| Section标题 | 1200 × 120~170 | 距边缘 48~64 单位 |
| 图表 | 1200 × 320~760 | 距边缘 48~64 单位 |

**画布设置原则：**
- 统一使用 `viewBox="0 0 1200 高度"` 作为基准
- 内容区域距离画布边缘至少 48 单位，推荐 64 单位
- 确保在不同显示宽度下内容都有足够呼吸空间

## 3. 渲染宽度与字号换算

### 换算公式

```
实际渲染字号 = SVG内字号 × 实际显示宽度 ÷ viewBox宽度
```

其中：
- SVG内字号：在viewBox坐标系下设置的font-size值
- 实际显示宽度：GitHub页面中SVG最终渲染的像素宽度
- viewBox宽度：统一为1200

### 900px桌面端字号标准（推荐）

| 文字层级 | SVG内字号（viewBox=1200） | 实际渲染字号（900px宽） |
|---------|--------------------------|------------------------|
| Hero主标题 | ≥ 64px | ≥ 48px |
| Section标题 | ≥ 54px | ≥ 40px |
| 重要文本/正文 | ≥ 27px | ≥ 20px |
| 标签/辅助文字 | ≥ 24px | ≥ 18px |

**字号计算公式验证：**
- Hero标题：64 × 900 ÷ 1200 = 48px ✓
- Section标题：54 × 900 ÷ 1200 = 40.5px ✓

## 4. SVG骨架模板

所有糖糖it主题的SVG必须包含以下完整骨架：

```svg
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 1200 360"
     role="img"
     aria-labelledby="svg-title svg-desc">
  <title id="svg-title">这里是SVG标题</title>
  <desc id="svg-desc">这里是SVG的详细描述，用于无障碍访问</desc>
  
  <!-- 内容开始 -->
  <rect width="1200" height="360" fill="#ffffff"/>
  <!-- 你的SVG内容 -->
  <!-- 内容结束 -->
</svg>
```

**必填属性说明：**
- `xmlns`：必须声明SVG命名空间
- `viewBox`：必须设置正确的视口坐标系
- `role="img"`：标识为图像元素，便于屏幕阅读器识别
- `aria-labelledby`：关联title和desc，提供无障碍文本
- `<title>`：SVG简短标题
- `<desc>`：SVG详细描述

## 5. 糖糖it各主题SVG注意事项

### 5.1 新野兽派（Blockframe）

- 使用 **4px 黑色或白色硬边框**，不使用圆角
- 色彩高饱和、高对比
- 几何形状为主，硬边切割
- 可以使用错位、重叠等大胆构图
- 文字使用粗体，字重 700+

### 5.2 糖蓝专业（Blue Professional）

- 使用 **软圆角**（圆角半径 8~16px）
- 善用蓝色系的 tint 浅色变体作为背景块
- 渐变柔和，避免强烈对比
- 留白充足，排版克制专业
- 装饰元素简洁，不喧宾夺主

### 5.3 紫金奢华（Purple Gold Presentation）

- 使用 **微妙的发光效果**（soft glow）
- 金色渐变要细腻，避免廉价感
- 紫色底色深邃有层次
- 光晕半径适中，控制在 8~16px
- 文字可以搭配细金边装饰

### 5.4 赛博朋克（Cyberpunk）

- 可以设计霓虹发光样式，但**不要使用SVG动画**
- 使用霓虹色：亮粉、电光蓝、荧光绿、亮黄
- 故障效果（Glitch）用静态层叠实现，不用animate
- 可以用错位的色块模拟故障感
- 边框可以使用斜切角度增加科技感

### 5.5 清新薄荷（Fresh Mint）

- 使用 **圆润形状**，大圆角（16~32px）
- 色彩清新柔和：薄荷绿、浅蓝、奶白
- 可以使用有机形状、波浪、圆形元素
- 阴影柔和，透明度适中
- 整体感觉轻盈、友好、清爽

### 5.6 暗色主题（Blockframe Dark）

- 在新野兽派基础上调整为暗色调
- 边框使用 4px 白色/浅灰硬边
- 背景深色，文字亮色
- 保持高对比度但不刺眼

## 6. CJK中文注意事项

### 字体设置

- **必须加载**：`font-family="Noto Sans SC, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif"`
- 如果使用特殊字体，请确认GitHub环境可渲染，或转为路径（path）
- 推荐字重：标题 700，正文 400~500

### 排版规范

- **字间距（letter-spacing）**：设置为 `0` 或正常值，中文不需要额外字间距
- **行高（line-height）**：多行文本设置为 `1.7~1.8`
- **不要使用 text-transform: uppercase**：中文没有大小写概念，会导致渲染异常
- **标签文字保持简短**：SVG内中文标签尽量控制在4~6字以内，避免换行
- **避免过长文本**：纯SVG不适合大段文字，大段内容应放在HTML中

### 中文渲染最佳实践

```svg
<text x="600" y="180" 
      font-family="Noto Sans SC, sans-serif" 
      font-size="64" 
      font-weight="700" 
      text-anchor="middle"
      fill="#1a1a1a">
  糖糖it标题
</text>
```
