# 展示贡献指南 🍬

如果你用糖糖it README 美化坊做出了满意的公开 README，欢迎提交展示！

## 提交条件

- 仓库必须是公开的
- 你必须是仓库的所有者或维护者
- README 必须实际使用了本 Skill 产出的视觉资产
- 展示完全可选，不提交也不影响使用

## 提交内容格式

每个展示条目包含：

```text
- **[仓库名](GitHub URL)** — 一句话描述项目如何使用了糖糖it的主题。使用的主题：xxx
```

例如：
```text
- **[my-awesome-cli](https://github.com/yourname/my-awesome-cli)** — 使用赛博朋克霓虹主题为 CLI 工具打造了终端风格 Hero 和流程图。使用的主题：cyberpunk-neon
```

## 审核标准

糖糖it会审核以下方面：

1. README 是否清晰传达了项目价值
2. 视觉是否与项目气质匹配
3. 是否有真实的证明（截图、输出、示例）
4. 是否遵循了所选主题的设计规范

## 提交流程

1. 确认你的 README 已上线且公开可访问
2. 准备好你的仓库链接和一句话简介
3. 通过 PR 或 Issue 提交给糖糖it
4. 等待审核结果

## 注意事项

- 署名「糖糖it出品」徽章完全可选，不是提交展示的必要条件
- 提交展示不等于糖糖it对你的项目做任何背书或担保
- 糖糖it有权决定哪些项目出现在展示列表中
- 可以随时请求从展示列表中移除你的项目
