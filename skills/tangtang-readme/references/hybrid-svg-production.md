# 混合SVG合成指南

> 作者：糖糖it

## 何时使用混合SVG

混合SVG合成方案适用于以下场景：

- **写实人物需求**：需要真实感人物肖像、表情细腻的角色
- **有机纹理**：布料质感、皮肤纹理、自然毛发等
- **复杂材质**：金属光泽、玻璃折射、皮革质感等难以用纯SVG绘制的材质
- **电影级光照**：体积光、全局光照、复杂阴影效果

纯SVG擅长矢量图形、几何形状、图标和排版，而AI生图擅长写实内容和复杂视觉效果，两者结合可以发挥各自优势。

## 工作流程

### 1. SVG布局层搭建
- 使用SVG创建基础布局框架
- 定义文本区域、装饰元素、几何图形
- 预留主体图片位置和尺寸
- 确定配色方案和设计规范

### 2. ImageGen生成主体
- 根据设计风格生成主体图片
- 提示词需明确风格、光照、构图
- 生成尺寸建议2x-3x目标尺寸，保证清晰度
- 生成多张候选，挑选最佳效果

### 3. 抠图去背景
- 使用专业抠图工具移除背景
- 处理发丝、半透明边缘等细节
- 输出为带透明通道的PNG格式
- 检查边缘是否有残留色边

### 4. 合成PNG/WebP
- 将SVG布局层与PNG主体合成
- 调整位置、大小、层级关系
- 添加阴影、光晕等融合效果
- 导出最终PNG或WebP格式

## 核心规则

### 精确文案规则
- **永远不要把精确文案放进AI生成层**
- 所有文字内容必须保留在SVG层，使用真实文本
- AI生成层只负责视觉主体，文字后期在SVG中添加
- 避免AI生成文字出现乱码、错别字问题

### 源文件保留规则
- 必须保留原始SVG布局源文件
- 必须保留抠图后的透明PNG素材
- 建议保留生成提示词和参数记录
- 方便后续修改和迭代

### 发布规则
- **发布最终合成的PNG/WebP文件**
- 不要发布依赖外部图片链接的SVG
- GitHub等平台对外链图片支持不稳定
- 单文件PNG/WebP兼容性最好，加载最可靠

## 各主题混合建议

### 赛博朋克主题
- 适合添加霓虹风格角色人物
- 机械义体、赛博格形象效果佳
- 霓虹光效人物与SVG几何元素结合
- 建议生成暗色调高对比度人物

### 新野兽派主题
- 适合贴纸风格的插画元素
- 手绘质感、粗犷线条的角色
- 复古贴纸、拼贴画风格
- 可生成多个小元素组合拼贴

### 清新薄荷主题
- 适合可爱风格插画
- 柔和配色的卡通角色
- 植物、小动物等自然元素
- 水彩、手绘质感效果佳

## 抠图注意事项

### 透明角检查
- 放大检查四个角落是否有残留像素
- 检查图片边缘是否有白边/黑边
- 使用棋盘格背景查看透明区域
- 确保背景完全透明无杂色

### 明暗背景测试
- 在白色背景下测试
- 在黑色背景下测试
- 在灰色背景下测试
- 检查边缘在不同背景下是否自然

### 边缘干净度
- 发丝等细节处理要自然
- 避免锯齿状边缘
- 半透明区域过渡要平滑
- 必要时手动修边处理

## 文件组织建议

```
project/
├── source/
│   ├── layout.svg          # SVG布局源文件
│   ├── character.png       # 抠图后的透明PNG
│   └── prompt.txt          # 生成提示词记录
├── temp/
│   └── generated-*.png     # AI生成的原始图片
└── final.png               # 最终合成输出
```
